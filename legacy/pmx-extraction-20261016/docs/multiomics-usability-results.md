## Registre détaillé des incidents

Inscrire un ticket par défaut reproductible, avec la tâche,
une reproduction anonymisée, le comportement observé, le
comportement attendu, la priorité P0/P1/P2 et le commit de
correction. Garder l'absence de résultat quand aucune session
n'a encore été réalisée.

## Critères avant de modifier l'affichage public

- Une session non réalisée n'est **pas** une réussite.
- Une réussite automatisée n'est **pas** une preuve d'utilisabilité.
- Une bonne compréhension de l'interface n'est **pas** une validation
  biologique, confirmatoire ou clinique.
