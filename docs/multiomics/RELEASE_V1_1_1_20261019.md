# MultiOmics 1.1.1 — ecosystem coherence patch

**Release date:** 19 October 2026  
**Software version:** `1.1.1`  
**Base scientific release:** `1.1.0` at `21e547ff275f35304ada304b7ada1ef95cbd4aa0`

MultiOmics 1.1.1 is an **ecosystem-coherence and reproducibility-hardening patch**. It does not add an omics method, change a statistical model, alter the Omics2PK exchange schema, or broaden any scientific or clinical claim.

## Changes

- replace the residual “Other disciplines / Autres disciplines” framing with **Ecosystem / Écosystème**;
- add the canonical `/multiomics/ecosystem/` overview while keeping `/multiomics/disciplines/` as a compatibility route;
- use the shared **Learn → Analyze → Integrate** positioning:
  - PMx Explain = Learn / Apprendre;
  - MultiOmics = Analyze / Analyser;
  - Omics2PK = Integrate / Intégrer;
- use the same ecosystem graphical abstract as the other ecosystem sites;
- retain separate repositories, provenance and explicit evidence boundaries;
- normalize the isolated MOFA2 Basilisk bootstrap tooling (`pip`, `wheel`, `setuptools`, `packaging`) to the already recorded exact lock before fitting, while keeping the existing full 18-package post-fit audit fail-closed.

## Scientific boundary

All scientific claims and limitations remain those of the 1.1.0 scientific line. The bootstrap normalization is a reproducibility control, not a change to MOFA2, preprocessing, seeds, data or factor interpretation. In particular, issues #44, #47 and #20 remain open limitations/perspectives.

No automatic biological causality, PK readiness, dosing or clinical-validity claim is transferred between tools.

PMx Explain may pin the exact qualified 1.1.1 SHA after all required MultiOmics workflows pass. The public site must not follow a moving branch.
