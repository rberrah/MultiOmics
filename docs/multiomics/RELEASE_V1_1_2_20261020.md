# MultiOmics 1.1.2 — MOFA2 reproducibility patch

**Release date:** 20 October 2026  
**Software version:** `1.1.2`  
**Base ecosystem release:** `1.1.1`

MultiOmics 1.1.2 is a **reproducibility patch only**. It does not change the MOFA2 model, Nutrimouse preprocessing, the statistical interpretation, the Omics2PK exchange contract, or any scientific/clinical claim.

## Reason for the patch

The post-merge 1.1.1 MOFA2 workflow completed all genuine Nutrimouse MOFA2 fits successfully, then failed the fail-closed environment audit because Basilisk's bootstrap installation resolved `setuptools 84.2.0` instead of the previously recorded `84.0.0`.

The actual scientific Python stack remained at the expected versions, including `mofapy2 0.7.3`, `numpy 1.26.4`, `scipy 1.12.0`, `pandas 2.2.1`, `h5py 3.10.0` and `scikit-learn 1.4.0`.

## Change

Before authentic MOFA2 fitting, the workflow now normalizes the small Basilisk bootstrap layer — `pip`, `wheel`, `setuptools` and `packaging` — to the exact versions already recorded in `mofa-python-pins.json`.

The existing post-fit audit remains fail-closed and independently verifies the resulting isolated Python environment.

## Scientific boundary

No biological result was rescued or reinterpreted. The 1.1.1 Nutrimouse MOFA2 fits themselves had already passed; the failed step concerned environment provenance after fitting.

Issues #44, #47 and #20 retain exactly the same status and interpretation.
