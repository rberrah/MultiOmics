# MultiOmics 1.1.3 — release provenance patch

**Release date:** 20 October 2026  
**Software version:** `1.1.3`  
**Base qualified release:** `1.1.2`

MultiOmics 1.1.3 is a **release-provenance patch only**. It does not change any omics method, statistical model, R/Python scientific dependency, MultiOmics → Omics2PK exchange schema, PK analysis or scientific/clinical claim.

## Why this patch exists

The 1.1.1 and 1.1.2 version bumps used broad string replacement in `package-lock.json`. That accidentally changed transitive package metadata while leaving the resolved tarballs and integrity hashes untouched:

- `@standard-schema/spec` was mislabeled while its locked tarball remained version 1.1.0;
- `picocolors` was mislabeled while its locked tarball remained version 1.1.1.

The installed dependency payloads did not change. The defect was in lockfile metadata/provenance.

## Change

1. Restore transitive dependency versions to the versions encoded by their existing resolved npm tarballs.
2. Keep the MultiOmics root package version independently versioned.
3. Add a release-gate contract that:
   - requires `package.json`, the lock root and `packages[""]` to agree;
   - checks npm-registry package versions against their resolved tarball filenames.
4. Future release bumps must change only the root project version fields, never arbitrary matching version strings in dependency entries.
