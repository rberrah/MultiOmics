# MultiOmics

A deterministic, research-oriented single- and multi-omics analysis environment.

> **Status:** independent repository bootstrap and reproducibility audit in progress.
> This repository is being extracted from [rberrah.github.io](https://github.com/rberrah/rberrah.github.io), pinned to source commit `dbe503f98cfde460f95a60617f3d743adb6b915b`.
> Do **not** treat this initial import as a separately validated release or a hosted reference R service.

## Scope

- Transcriptomics, proteomics and metabolomics, individually or combined.
- Exploratory browser calculations clearly distinguished from native R reference methods.
- Reproducible research bundles including full reference tables, R scripts, an annotated R Markdown notebook and equivalent R figures where supported.
- Beginner-friendly educational material, validations on public datasets and defined study-design guardrails.

## Migration policy

The [existing public application](https://rberrah.github.io/pharmacometrie/multiomics/tool/) remains hosted by the original site during this transition. No live route is redirected to this repository until this repository independently builds, passes its scientific validations, and is published without breaking existing links.

Method-specific reproducibility must not be mistaken for universal FDR control, clinical validation or confirmed biomarker utility.

See `docs/multiomics/REPOSITORY_EXTRACTION_ADR.md` after the import for staged extraction details.
